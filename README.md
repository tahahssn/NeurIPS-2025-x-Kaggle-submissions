# 🏆 NeurIPS 2025 x Kaggle - Google Code Golf Championship

## 📌 Overview

This repository contains **all official submissions and experiments** from our participation in the **Google Code Golf Championship**, a featured **NeurIPS 2025 competition** hosted on **Kaggle**.

The competition focused on **code golf**, minimizing code length while preserving correctness and performance — pushing participants to explore creativity, deep optimization, and unconventional problem-solving strategies.
